## 🎯 5个问题的答案

### 1️⃣ 存储结构如何设计？

**答案：双表示法 + 分层存储**

```json
{
  "id": "q_001",
  "content": {
    "stem_latex": "已知椭圆 $\\frac{x^2}{4}+\\frac{y^2}{3}=1$",
    "stem_plain": "已知椭圆 x²/4 + y²/3 = 1",
    "options_latex": {"A": "$2x-y-5=0$", ...},
    "options_plain": {"A": "2x-y-5=0", ...}
  },
  "normalized_text": "已知椭圆x2/4+y2/3=1...",
  "description": "求椭圆周长问题，考查椭圆定义和焦点性质",
  "source_meta": {"region": "山东省", "year": 2025, ...}
}
```

**优势：**
- LaTeX用于PDF渲染（质量最高）
- 普通文本用于内容对比（评测）
- 规范化文本用于向量化（一致性）
- 描述用于语义搜索（RAG精度+20%）

---

### 2️⃣ 先生成普通格式还是先生成LaTeX？

**答案：先生成LaTeX，再转换为普通格式**

```
PDF/OCR输出（混乱）
    ↓
LLM规范化为LaTeX（结构化）
    ↓
保存LaTeX版本
    ↓
转换为普通文本
    ↓
生成规范化文本
    ↓
向量化存储
```

**理由：**
- LaTeX是规范化的中间表示（标准写法）
- OCR输出通常混乱（x²/4 vs x^2/4 vs x2/4）
- LaTeX→普通文本是单向的（可逆性好）

---

### 3️⃣ 如何将LaTeX格式规范化？

**答案：LLM规范化 + 正则后处理**

| 变体 | 标准形式 |
|------|--------|
| `\dfrac{x}{y}` | `\frac{x}{y}` |
| `x^2` | `x^{2}` |
| `\times` | `\cdot` |
| `/` | `\div` |
| `\left( \right)` | `( )` |
| `\vec{AB}` | `\overrightarrow{AB}` |

**实现方式：**
1. 用LLM处理复杂情况（准确率高）
2. 用正则处理简单情况（速度快）
3. 验证规范化是否改变数学含义

---

### 4️⃣ 要不要生成自然语言描述？

**答案：生成基础描述（必做），可选生成丰富描述**

**对RAG的影响：**
- 无描述：检索精度 60%
- 基础描述：检索精度 80% (+20%)
- 丰富描述：检索精度 90% (+40%)

**建议：**
- 现在：生成基础描述（模板，0成本）
- 未来：生成丰富描述（LLM，中等成本）
